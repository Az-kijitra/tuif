# Spec ID 台帳 (`tuif`)

階層構造で仕様を管理する。Spec IDは `SPEC-<領域番号>-<連番>` 形式(例: `SPEC-0100-0001`)。

## 領域一覧

| 領域番号 | 領域名 | ディレクトリ | 説明 |
|---|---|---|---|
| 0100 | プロダクト方針 | `specs/product/` | 目的・基本コンセプト・GUI版からの踏襲と変更境界 |
| 0200 | アーキテクチャ・技術基盤 | `specs/architecture/` | 技術スタック(Rust + Ratatui)、モジュール構成、ターミナル制御 |
| 0300 | コア機能 | `specs/features/` | CUIファイラーとしてのユーザー向け機能・Vim-likeキーマップ・外部ツール連携 |
| 0400 | 品質・テスト | `specs/quality/` | テスト戦略(`TestBackend` によるTUIテスト、単体テスト)、品質基準 |
| 0500 | ドキュメント | `specs/documentation/` | README / マニュアル / PowerShell統合スクリプトの要件 |
| 0600 | 配布・リリース | `specs/release/` | リリースビルド・配布構成 |
